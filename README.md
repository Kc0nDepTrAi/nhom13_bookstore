# Dự án Website Bán Sách - BOOKSTORE123
- Nhóm thực hiện: Nhóm 13
- Thành viên 3: Khải (Phụ trách thư mục public)

Giao diện Stitch được tích hợp với backend PHP hiện có. Hướng dẫn chạy XAMPP: [XAMPP_RUN.md](XAMPP_RUN.md).

Với cơ sở dữ liệu mới, nhập `bookstore.sql`. Với cơ sở dữ liệu cũ, sao lưu trước rồi chạy `db/revision_1.sql` để thêm trường ghi chú, phương thức thanh toán và đánh giá; không nhập lại dữ liệu mẫu.

QR hiện là bản demo, không thực hiện hoặc xác minh chuyển khoản ngân hàng.
